Full Feature List

Everything you need for moderation, engagement, support, games, and server growth in one bot.

Community management

  • Welcome, leave, and boost messages with customizable buttons
  • Easy-to-use permissions and settings through /config ...
  • Support system for bug reporting via /support
  • Sticky messages and timed auto messages
  • Tickets system with workload measurement, transcripts, and more
  • Rewards for members using your server tag

Fun and engagement

  • Advanced giveaway system for events and milestones
  • TicTacToe with adjustable AI levels
  • Random commands like /coinflip, /dadjoke, /TicTacToe, and /dice
  • Levelling, achievements, AFK, and one-word story
  • Tags and lightweight role-play/community interactions

Server operations

  • Counting system with protection, leaderboard support, and reset controls
  • YouTube notifications for creators and community updates
  • Moderation and utility actions like /purge and /say
  • Logging to track key server events
  • New features are added every few weeks!!!
